Description

Above is a list of the courses that have had changes approved through NTU’s Curriculum Refresh programme which aims to embed sustainability into all course and module content offered by the University.

The list also includes courses with sustainability already embedded, and those that include the Sustainability in Practice Certificate as part of the core curriculum.

Total number of courses with sustainability embedded for courses running: 185
